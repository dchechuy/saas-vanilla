# Quick Start Guide

## First login

1. Sign in with `admin` / `Changeme-123`.
2. Change the password immediately.
3. Review users, permissions, and system configuration.

## Bootstrap a new SaaS prototype

1. Copy this repository or create a new repo from this template.
2. Rename product-facing labels and branding.
3. Add the domain-specific modules for your customer use case.
4. Keep all release notes and product docs in `docs/`.
